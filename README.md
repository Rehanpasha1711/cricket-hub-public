# CricketHub

One combined folder containing frontend and backend.

## Run
1. Install Node.js.
2. Open this folder in VS Code.
3. Terminal:
   npm install
   npm start
4. Open http://localhost:5000

## GitHub
Upload the ENTIRE `cricket-hub-public` folder as one repository. Do not upload frontend and backend separately.

## Includes
- Player search
- Player cards and statistics
- T20I, ODI and Test batting/bowling/all-rounder/team rankings
- Player photos/placeholders
- Premium bats, bowling gear and cricket kits above ₹1 lakh
- Marketplace links
- Responsive decoration

Ranking/product entries are demo data for a student project. Verify current rankings, prices and availability before publishing as live information.
